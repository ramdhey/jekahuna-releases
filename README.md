# Jekahuna — releases

Installers for **Jekahuna**, a local-first API client (web + desktop).

Download the latest version from [Releases](https://github.com/ramdhey/jekahuna-releases/releases/latest):

| File | For |
|---|---|
| `Jekahuna-Setup-x.y.z.exe` | Windows 10/11 (64-bit) |
| `Jekahuna-x.y.z-arm64.dmg` | Mac with Apple Silicon (M1–M4) |
| `Jekahuna-x.y.z.dmg` | Mac with Intel |

Installed apps update themselves from this repository. This repository only contains release files; the source code is private.
